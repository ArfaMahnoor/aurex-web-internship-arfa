## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- DOM Manipulation
- localStorage

## Features Implemented

- Add task
- Edit task
- Delete task
- Mark task as complete / undo
- Filter tasks (All, Active, Completed)
- Form validation with error messages (empty tasks are rejected)
- Tasks saved in localStorage
- Tasks retrieved after page refresh
- Stored tasks update when tasks are edited, completed or deleted
- Responsive interface for mobile and desktop
